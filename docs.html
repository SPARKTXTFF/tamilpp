Welcome to the official documentation for TamilPP! This language allows you to write Python logic using native Tamil words or Tanglish (English-typed Tamil). Below are the core concepts and examples.

1. உள்ளீடு & வெளியீடு (Input & Output)

Use these keywords to print text to the screen and ask the user for information.

TamilTanglishPython Equivalent
பதி / காட்டு / சொல்லுpathi / padiprint
உள்ளிடுulliduinput

Tamil Example

பெயர் = உள்ளிடு("உங்கள் பெயர்: ")
பதி("வணக்கம்", பெயர்)

Tanglish Example

name = ullidu("Peyar: ")
padi("Vanakkam", name)

2. நிபந்தனைகள் (Conditionals)

Used to make decisions in your code based on true or false conditions.

TamilTanglishPython Equivalent
எனில்enilif
ஆனால்aanaalelif
இல்லைillaielse

Tamil Example

மதிப்பெண் = 85

எனில் மதிப்பெண் > 80:
    பதி("சிறப்பு!")
ஆனால் மதிப்பெண் > 35:
    பதி("தேர்ச்சி")
இல்லை:
    பதி("தோல்வி")

Tanglish Example

mark = 85

enil mark > 80:
    padi("Super!")
aanaal mark > 35:
    padi("Pass")
illai:
    padi("Fail")

3. சுழல்கள் (Loops & Flow Control)

Used to repeat actions multiple times.

TamilTanglishPython Equivalent
சுற்றுsutrufor
வரைvaraiwhile
நிறுத்துniruthu / stopbreak
தொடர்thodarcontinue

Tamil (For Loop)

# பட்டியலை சுழற்றுதல்
சுற்று எண் இல் [1, 2, 3]:
    பதி(எண்)

Tanglish (While Loop)

# 5 வரும் வரை ஓடும்
x = 0
varai x < 5:
    enil x == 3:
        niruthu
    padi(x)
    x = x + 1

4. தருக்க வார்த்தைகள் (Logical Operators & Booleans)

Used to combine multiple conditions.

TamilTanglishPython Equivalent
மற்றும் / அல்லது / இல்லாதmatrum / allathuand / or / not
உண்மை / பொய்unmai / poiTrue / False

Tamil Example

மழை = உண்மை
குடை = உண்மை

எனில் மழை மற்றும் குடை:
    பதி("பாதுகாப்பான பயணம்")

Tanglish Example

mazhai = unmai
kudai = unmai

enil mazhai matrum kudai:
    padi("Safe journey")

5. செயல்பாடுகள் (Functions)

Used to create reusable blocks of code.

TamilTanglishPython Equivalent
செயல்seyaldef
திருப்புthiruppureturn

Tamil Example

செயல் பெருக்கு(அ, ஆ):
    விடை = அ * ஆ
    திருப்பு விடை

பதி(பெருக்கு(5, 5)) # 25

Tanglish Example

seyal multiply(a, b):
    ans = a * b
    thiruppu ans

padi(multiply(5, 5)) # 25
