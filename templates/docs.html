Welcome to TamilPP, a custom Python-based programming language designed to make coding accessible in both pure Tamil script and English-typed Tanglish. TamilPP compiles directly into Python, giving you full native power!

1. Variables and Printing (பதி / காட்டு)

Declare variables naturally or use the optional அமை (set) keyword. Print using பதி, காட்டு, சொல்லு, or Tanglish equivalents.

Pure Tamil

அமை பெயர் = "Spark"
அமை வயது = 21

பதி("வணக்கம்", பெயர்)
காட்டு("உங்கள் வயது:", வயது)

Tanglish

set peyar = "Spark"
set vayathu = 21

padi("Vanakkam", peyar)
sollu("Ungal vayathu:", vayathu)

2. Taking User Input (உள்ளிடு)

Ask the user for information using உள்ளிடு (input). Cast data types using முழுஎண் (int) or சரம் (str).

Pure Tamil

அமை பயனர்_பெயர் = உள்ளிடு("உங்கள் பெயர் என்ன? ")
பதி("வரவேற்கிறோம்", பயனர்_பெயர்)

அமை பிறப்பு_ஆண்டு = முழுஎண்(உள்ளிடு("பிறந்த ஆண்டு: "))

3. Conditionals (எனில் / ஆனால் / இல்லை)

Control flow using logic. Supported operators include மற்றும் (and), அல்லது (or), and இல்லாத (not).

Tanglish

set mark = 85

if mark >= 90:
    sollu("Super!")
elif mark >= 50 matrum mark < 90:
    sollu("Pass aagiteenga")
else:
    sollu("Fail, try again")

4. Loops (சுற்று / வரை)

Repeat actions using சுற்று (for loops) and வரை (while loops).

Pure Tamil (For Loop)

அமை பழங்கள் = ["மாம்பழம்", "பலா", "வாழை"]

சுற்று பழம் இல் பழங்கள்:
    பதி("எனக்கு பிடிக்கும்:", பழம்)

5. Functions (செயல் / திருப்பு)

Group reusable code using செயல் (def) and return values using திருப்பு (return).

Tanglish

seyal koottal(num1, num2):
    set vidai = num1 + num2
    thiruppu vidai

set total = koottal(10, 15)
sollu("Total is:", total)
